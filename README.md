# English Master Pro 📚

تطبيق تعلم المفردات الإنجليزية — يعمل محلياً 100% على جهاز الطالب، بدون سيرفر وبدون إنترنت بعد أول فتحة.

## الرابط المباشر للطلاب

**https://ammarrantisie-ops.github.io/english-master-pro/**

## كيف يعمل؟

- كل طالب يفتح الرابط على هاتفه، ينشئ حساباً (اسم + صف + كلمة مرور).
- **التقدم (نقاط XP، الكلمات المتمكنة، الممارسات) محفوظ على جهاز الطالب نفسه** (localStorage) — لا يُرفع لأي سيرفر.
- **المحتوى (الكلمات والوحدات) مشترك ومركزي** في ملف `content.json` في هذا المستودع.
- زر **"📤 إرسال تقرير تقدمي للمعلم"** في الملف الشخصي يفتح واتساب المعلم برسالة جاهزة بتقرير الطالب اليومي (مرة كل 24 ساعة).
- **📝 قسم الممارسة:** يختار الطالب كلمة من كلماته، فيُعرض عليه سياق جملة إنجليزية فيها فراغ، وعليه اختيار الكلمة الصحيحة التي تُكمل المعنى — تمرين على الفهم وليس على الترجمة.

## نشر تعديلات الكلمات للطلاب (خطوات المعلم)

1. ادخل التطبيق كمعلم (كلمة مرور `admin123`).
2. في تبويب **"⚙️ إدارة الصفوف"** أضف/عدّل/احذف الصفوف والوحدات والكلمات.
3. **للحذف والإضافة تصل للطلاب فوراً**: اضغط **"🚀 نشر التعديلات للطلاب الآن"** بعد أي تعديل — يرفع التطبيق `content.json` مباشرة إلى GitHub، فيسحب كل الطلاب النسخة المحدّثة تلقائياً عند فتح التطبيق (مع الحفاظ على تقدم كل طالب).
   - تحتاج مرة واحدة فقط إدخال **رمز GitHub** (Fine-grained token بصلاحية `Contents: Read and write` لهذا المستودع) في حقل "نشر التعديلات للطلاب"، ثم حفظه. الرمز يُحفظ على جهاز المعلم فقط.
   - يظهر شريط تنبيه **"لديك تعديلات لم تصل للطلاب بعد"** عندما يكون هناك حذف/إضافة غير منشورة.
4. طريقة بديلة: اضغط **"⬇️ تنزيل content.json"** واستبدل محتوى `content.json` في هذا المستودع ثم احفظ التعديل (من GitHub مباشرة أو عبر git push).

> عندما يفتح الطالب التطبيق، يسحب تلقائياً أحدث `content.json` وستظهر الإضافات والحذف فوراً، مع الحفاظ على تقدمه السابق.

> **بدون إنترنت:** التطبيق يخزّن آخر نسخة (Service Worker) فيعمل الطالب بها حتى انقطاع الاتصال، وتُدمج محلياً الإضافات عند العودة للإنترنت.

## حساب عدد التمارين حسب تقدم الطالب

- **تمرين المعاني (ما ترجمة؟):** عدد الأسئلة = عدد الكلمات التي حفظها الطالب فعلاً (الكلمات التي أتقنها), لا يُقتطع إلى عشرة.
- **قسم الممارسة:** عدد الأسئلة = 70% من عدد الكلمات المتعلمّة (4 على الأقل). مثال: حفظ 40 كلمة ← 28 تمرين ممارسة.

## الصيغة/المواصفات

### content.json

```
{ "version": 1, "updated": "2026-09-04", "grades": [...] }
```

كل كلمة يمكن أن تحمل جملة مثال (تُستخدم في قسم الممارسة):
```
{ "id": 1, "word": "apple", "translation": "تفاحة", "cat": "n", "done": false, "en_s": "I eat an apple every day.", "ar_s": "آكل تفاحة كل يوم." }
```

- `cat` نوع الكلمة: `n` اسم / `v` فعل / `adj` صفة (يختاره المعلم عند الإضافة لتحسين الجمل المولّدة).
- لأي كلمة بدون جملة، يضيف التطبيق جملة تلقائياً حسب نوعها — زر **🤖 توليد جمل تلقائي** في فقرة "يدوية" يغطي كل الكلمات (يعمل بدون إنترنت).

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | التطبيق نفسه (ملف واحد، لا يوجد بناء) |
| `content.json` | المحتوى المشترك (الكلمات/الوحدات/الصفوف) |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `manifest.webmanifest` + `icon.svg` | تثبيت التطبيق على شاشة الجوال |
