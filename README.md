# English Master Pro 📚

تطبيق تعلم المفردات الإنجليزية — يعمل محلياً 100% على جهاز الطالب، بدون سيرفر وبدون إنترنت بعد أول فتحة.

## الرابط المباشر للطلاب

**https://ammarrantisie-ops.github.io/english-master-pro/**

## كيف يعمل؟

- كل طالب يفتح الرابط على هاتفه، ينشئ حساباً (اسم + صف + كلمة مرور).
- **التقدم (نقاط XP، الكلمات المتمكنة، الاختبارات) محفوظ على جهاز الطالب نفسه** (localStorage) — لا يُرفع لأي سيرفر.
- **المحتوى (الكلمات والوحدات) مشترك ومركزي** في ملف `content.json` في هذا المستودع.
- زر **"📤 إرسال تقرير تقدمي للمعلم"** في الملف الشخصي يفتح واتساب المعلم برسالة جاهزة بتقرير الطالب اليومي (مرة كل 24 ساعة).

## نشر تعديلات الكلمات للطلاب (خطوات المعلم)

1. ادخل التطبيق كمعلم (كلمة مرور `admin123`).
2. في تبويب **"⚙️ إدارة الصفوف"** أضف/عدّل الصفوف والوحدات والكلمات.
3. اضغط **"⬇️ تنزيل content.json"** ليُحمَّل الملف على جهازك.
4. استبدل محتوى `content.json` في هذا المستودع بالملف المُحمّل ثم **احفظ التعديل** (من GitHub مباشرة أو عبر git push).

   > عندما يفتح الطالب التطبيق، يسحب تلقائياً أحدث `content.json` وستظهر الإضافات فوراً، مع الحفاظ على تقدمه السابق.

> **بدون إنترنت:** التطبيق يخزّن آخر نسخة (Service Worker) فيعمل الطالب بها حتى انقطاع الاتصال، وتُدمج محلياً الإضافات عند العودة للإنترنت.

## نشر الاختبارات (اختبارات المعلم لطلابه)

1. اطلب من أي ذكاء اصطناعي (ChatGPT / Gemini / Claude) توليد اختبار بالصيغة التالية:

```json
[{"id":1,"title":"اختبار الوحدة الأولى","grade":1,"questions":[
  {"q":"ما معنى apple؟","type":"mc","options":["تفاحة","كتاب","قطة","طاولة"],"answer":0,"explanation":"apple = تفاحة"},
  {"q":"cat تعني كلب","type":"tf","answer":false,"explanation":"cat = قطة"},
  {"q":"أكمل: I ___ a student.","type":"fill","answer":"am"}
]}]
```

- **mc** = اختيار من متعدد (الخيار الصحيح رقمه `answer` بدأً من 0)
- **tf** = صحيح/خطأ (`answer`: true أو false)
- **fill** = أكمل الفراغ (`answer`: الكلمة)

2. في التطبيق: تسجيل دخول معلم → تبويب **🧪 اختبارات** → الصق المخرجات → **"➕ إضافة/استبدال من النص"** → **⬇️ تنزيل content.json** → ارفعه في هذا المستودع.
3. بمجرد فتح الطالب للتطبيق يرى الاختبار الجديد فوراً.

## الصيغة/المواصفات

### content.json

```
{ "version": 1, "updated": "2026-09-04", "grades": [...], "tests": [...] }
```

كل كلمة يمكن أن تحمل جملة مثال:
```
{ "id": 1, "word": "apple", "translation": "تفاحة", "done": false, "en_s": "I see an apple.", "ar_s": "أرى تفاحة." }
```

النظام يضيف/يولّد جملة مثال لأي كلمة ليس لديها جملة (`en_s` / `ar_s`) — في فقرة "يدوية" يوجد زر **🤖 توليد جمل تلقائي** لجميع الكلمات (يعمل بدون إنترنت).
